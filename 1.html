Python-Interpreter

2-4 2.3, 2.4

Python-Programme werden von einem Interpreter ausgeführt.

Interaktiver Interpreter

$ python
Python 3.14.3 (main, Feb 18 2026, 14:35:05) on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> 5+3
8

Script-Interpreter

$ python meinprogramm.py
Python-Programme werden nicht compiliert, sondern zur Laufzeit interpretiert. Um schnell etwas mit Python herumzuspielen, kann man interaktiv direkt auf der Shell Kommandos eingeben. Wie das Kommando 5+3 zeigt, muss man in der Python-Shell nicht zwangsweise den print-Befehl verwenden. Jede Rückgabe, die ein Kommando liefert wird ausgegeben. Die Python-Shell bietet auch eine Autovervollständigung (Tab-Taste). Mit Strg+D (MacOS: ^D) kann die Python-Shell beendet werden.

Beispiel-Programm

2.4

meinprogramm.py

Starten:

$ python meinprogramm.py

Ausgabe:

Hallo!
8
Die Funktion print gibt etwas auf der Konsole aus. Das hier dargestellte Programm lässt sich mittels python meinprogramm.py starten. Es gibt auf der Konsole Hallo! aus und in der nächsten Zeile die Zahl 8.

Übung 1.1

Machen Sie sich mit Python und Visual Studio Code vertraut:

  1. Installieren Sie Visual Studio Code und die Python-Erweiterung
    (Tipp: Einfach eine .py-Datei anlegen, dann fragt VS Code nach der Installation der Python-Erweiterung)
  2. Öffnen Sie ein Terminal in Visual Studio Code (oben im Menü) und starten Sie die interaktive Python-Konsole mittels python, rechnen Sie etwas aus und spielen Sie mit Variablen.
  3. Schreiben Sie simplen Programmcode, um etwas zu berechnen in eine uebung_1_1.py und führen Sie sie aus.
  4. Nutzen Sie das Umbenennen-Feature in VS-Code, um eine Variable an allen Stellen umzubenennen (Rechtsklick → Rename Symbol).

Jupyter

24 2.6

Jupyter Notebook ist eine open-source Webanwendung, um interaktive wissenschaftliche Datenauswertungen und Berechnungen durchzuführen.

  • Eingabe- und Ausgabezellen
  • Code
  • Text / Markdown
  • Diagramme
  • ...

Strg+Enter führt aktuelle Zelle aus.

.ipynb-Dateien lassen sich mit Jupyter Notebook, Jupyter Lite und auch mit Visual Studio Code öffnen.

Jupyter Notebooks in VS Code

  • Select Kernel (oben rechts): Lautzeitumgebung (z. B. Python 3.10.12)
  • Esc/Enter: Wechsel in den Kommandomodus / Editierenmodus
  • A / B im Kommandomodus (+Code) fügt Code-Block ober-/unterhalb ein
  • +Markdown fügt Text-Block hinzu:
    # Überschrift, **fett**, *kursiv*, - Liste, ...
  • D D im Kommandomodus: aktuellen Block löschen
  • Strg+Enter: Aktuelle Zelle ausführen
  • Shift+Enter: Aktuelle Zelle ausführen und weiter zur nächsten Zelle

Übung 1.2

Jetzt geht's um Jupyter-Notebooks in Visual Studio Code:

  1. Installieren Sie die Python-Erweiterung für Visual Studio Code
    (Tipp: Einfach eine .ipynb-Datei anlegen, dann fragt VS Code nach der Installation der Erweiterung)
  2. Erstellen Sie eine Markdown-Zelle mit coolem Inhalt (Überschriften, Text, ...)
  3. Erstellen Sie eine Code-Zelle, in der Sie Berechnungen durchführen und mit print Ergebnisse und Text ausgeben.
  4. Erstellen Sie eine weitere Code-Zelle, in der Sie ebenfalls eine Berechnung ausführen, nun jedoch ohne print das Ergebnis ausgeben, indem Sie einfach einen Variablennamen in die letzte Zeile der Codezelle schreiben.
